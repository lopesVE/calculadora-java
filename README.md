# 🧮 Calculadora em Java

Projeto de uma calculadora simples desenvolvida em **Java**, criada com o objetivo de praticar lógica de programação e conceitos fundamentais da linguagem.

## 📌 Sobre o projeto

A calculadora funciona diretamente pelo terminal e permite que o usuário escolha uma operação matemática, informe dois números e visualize o resultado.

Após realizar uma operação, o programa permite continuar utilizando a calculadora ou encerrar a execução.

## ⚙️ Funcionalidades

Atualmente, a calculadora possui as seguintes operações:

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🔄 Possibilidade de realizar várias operações sem reiniciar o programa
- ❌ Validação de opções inválidas

Durante o desenvolvimento deste projeto foram utilizados conceitos como:
